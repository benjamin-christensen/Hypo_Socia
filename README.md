- The Hypo_Socia Agent-Based Model (ABM) was designed for a research paper proposing to analyze levels of emergent behavior in complex (ecological) systems with the help of Integrated Information Theory (IIT).

- Versions 1 and 2 of IIT_ABM include the calculations performed using the PyPhi library for this purpose.

- For more details, see the preprint, “Assessing Causal Dynamics and Levels of Emergence in Social-Ecological Systems with PyPhi”.
